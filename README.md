# MAX Chat Link Finder

Небольшое Windows-приложение для поиска ссылок на чаты и каналы MAX в тексте,
локальных файлах и на веб-страницах. Приложение работает без сторонних
зависимостей и не отправляет содержимое файлов на внешние сервисы.

## Возможности

- распознаёт ссылки `https://max.ru/...` и `max://...`;
- удаляет дубликаты и знаки пунктуации вокруг ссылок;
- читает текстовые файлы в UTF-8 и Windows-1251;
- загружает HTML по `http`/`https` с ограничением размера ответа;
- позволяет скопировать результат или сохранить его в UTF-8.

## Запуск

Требуется Python 3.10 или новее.

```powershell
py -m max_chat_link_finder
```

Или дважды щёлкните `run.bat`.

## Тесты

```powershell
py -m unittest discover -s tests -v
```

## Сборка `.exe`

После установки PyInstaller (`py -m pip install pyinstaller`) запустите:

```powershell
build.bat
```

Готовый файл появится в `dist\MAX Chat Link Finder.exe`.
