# MAX Chat Link Finder

Windows-приложение автоматизирует **официальный** веб-клиент
[`web.max.ru`](https://web.max.ru/) через Playwright. Пользователь самостоятельно
входит в MAX в открытом Chromium; сессия остаётся в постоянном локальном профиле
`~/.max-chat-link-finder/browser-profile`.

## Безопасный обход

Программа ищет строки диалогов в виртуализированном списке MAX и проверяет как
DOM-атрибуты, так и модель компонента React. Строка открывается только при явном
признаке `group`/`chat`/`isGroup`; исключающие признаки direct message, канала,
системного или официального чата имеют приоритет.
Direct messages, каналы, системные и неизвестные типы не открываются. В каждой
подтверждённой группе открываются сведения о группе и вкладка «Ссылки». После
прокрутки сохраняются исключительно адреса вида `https://max.ru/join/<token>`.
Ссылки профилей `max.ru/u`, Telegram, VK и любые другие адреса отбрасываются.

Результат каждого запуска записывается одновременно в JSON, CSV (UTF-8 с BOM) и
SQLite. Диагностический режим включает Playwright trace и снимки экрана при
ошибках; файлы находятся в `~/.max-chat-link-finder/diagnostics`.

> MAX может менять разметку веб-клиента. По принципу fail-safe приложение не
> станет угадывать тип чата: если явный признак группы отсутствует, чат будет
> пропущен. Актуальные селекторы сосредоточены в `automation.py`. Если ни одна
> группа не распознана, диагностический режим сохраняет PNG, HTML и JSON-инвентарь
> элементов страницы в папку `~/.max-chat-link-finder/diagnostics`.

## Запуск из исходников

Требуются Python 3.10+ и Windows 10/11:

```powershell
py -m pip install -r requirements.txt
py -m playwright install chromium
py -m max_chat_link_finder
```

То же самое выполняет `run.bat`. Сначала нажмите «Открыть MAX и войти», завершите
вход в браузере и лишь затем запускайте проверку.

## Тесты

```powershell
py -m unittest discover -s tests -v
```

## Сборка Windows

```powershell
build.bat
```

Скрипт сначала запускает тесты, затем создаёт `dist\MAX Chat Link Finder.exe` и
устанавливает совместимый Chromium в `dist\browser`. Для работы нужны оба
компонента, поэтому распространять следует всю папку `dist`.
