# MAX Chat Link Finder

Windows-приложение автоматизирует **официальный** веб-клиент
[`web.max.ru`](https://web.max.ru/) через Playwright. Пользователь самостоятельно
входит в MAX в открытом Chromium; сессия остаётся в постоянном локальном профиле
`~/.max-chat-link-finder/browser-profile`.

## Обход чатов

Программа ищет видимые строки под полем «Найти» по их геометрии, а также проверяет
DOM-атрибуты и модель компонента React. Обрабатываются как групповые, так и личные
чаты. Каналы исключаются по признакам модели, а официальный диалог и другие
служебные диалоги исключаются, если их название содержит `MAX` без учёта регистра.
Левая навигация «Все», «Новые», «Каналы», «Контакты» и «Звонки» не участвует в
поиске: кандидаты берутся исключительно из области списка под поисковой строкой
в открытом разделе «Все».

Для каждого кандидата выполняется фиксированная последовательность: открыть чат,
нажать его название в верхней панели, дождаться страницы «Инфо», нажать «Ссылки»
и прокрутить фактическую прокручиваемую область страницы информации. После
прокрутки сохраняются исключительно адреса вида `https://max.ru/join/<token>`.
Ссылки профилей `max.ru/u`, Telegram, VK и любые другие адреса отбрасываются.

Перед первым открытием программа быстро прокручивает весь виртуализированный
список сверху вниз и сохраняет упорядоченный снимок названий/идентификаторов. Затем
список возвращается наверх, а сохранённые чаты открываются через поле поиска в
порядке снимка. Поэтому новые сообщения и перемещение чатов наверх во время
длительной проверки не приводят к пропускам или повторной обработке.

Результат каждого запуска записывается одновременно в JSON, CSV (UTF-8 с BOM,
разделитель `;` для корректных отдельных столбцов в русской версии Excel) и
SQLite. Диагностический режим включает Playwright trace и снимки экрана при
ошибках; файлы находятся в `~/.max-chat-link-finder/diagnostics`.

> MAX может менять разметку веб-клиента. Актуальные селекторы и геометрический
> поиск сосредоточены в `automation.py`. Если ни один чат не распознан,
> диагностический режим сохраняет PNG, HTML и JSON-инвентарь
> элементов страницы в папку `~/.max-chat-link-finder/diagnostics`.

## Запуск из исходников

Требуются Python 3.10+ и Windows 10/11:

```powershell
py -m pip install -r requirements.txt
py -m playwright install chromium
py -m max_chat_link_finder
```

То же самое выполняет `run.bat`. Сначала нажмите «Открыть MAX и войти», завершите
вход в браузере и лишь затем запускайте проверку.

## Тесты

```powershell
py -m unittest discover -s tests -v
```

## Сборка Windows

```powershell
build.bat
```

Скрипт сначала запускает тесты, затем создаёт `dist\MAX Chat Link Finder.exe` и
устанавливает совместимый Chromium в `dist\browser`. Для работы нужны оба
компонента, поэтому распространять следует всю папку `dist`.

## Диагностика списка «Все»

Если список чатов не прокручивается или строки пропускаются, используйте отдельную
[памятку и диагностический сценарий](docs/MAX_ALL_CHATS_AUTOMATION.md). Он создаёт
снимок всего виртуализированного списка, не открывая чаты.
