# Памятка для автоматизации списка «Все» в MAX

Этот текст можно целиком передать другому разработчику или вставить в новый чат с
ИИ вместе с `tools/inspect_max_all_chats.py`.

## Готовое техническое задание

> Автоматизируй официальный `https://web.max.ru` через Python Playwright.
> Пользователь входит вручную в persistent Chromium context. Перед обработкой
> обязательно нажми левый раздел **«Все»** и работай только со списком под полем
> поиска **«Найти»**. Не используй глобальные `[role=listitem]`, `div` или текстовые
> селекторы: они захватывают левую навигацию «Все», «Новые», «Каналы», «Контакты» и
> «Звонки».
>
> У MAX виртуализированный список. Сначала найди поле `input[placeholder^=Найти]`.
> Строками чатов считай только видимые прямоугольники ниже этого поля, имеющие ту
> же левую/правую границу и высоту примерно 58–135 px. Поднимайся от строки к
> родителям, пока не найдёшь элемент с `overflow-y: auto|scroll` и
> `scrollHeight > clientHeight`. Прокручивай именно `scrollTop` этого элемента, а
> не страницу и не колесо мыши.
>
> До открытия чатов сделай быстрый полный снимок списка: `scrollTop=0`, собрать
> видимые строки, сдвинуться на `0.8 * clientHeight`, дождаться перерисовки,
> повторить до неизменного `scrollTop`. Дедупликация: DOM chat id, затем href,
> затем `casefold(name) + avatar src`. Верни `scrollTop=0`. Только после этого
> открывай сохранённые чаты. Чтобы новые сообщения не меняли порядок и не
> приводили к пропускам, находи каждый сохранённый чат через поле «Найти».
>
> Не сохраняй `Locator.nth()` между кликами: React MAX заменяет DOM-узлы после
> открытия чата, и старые позиционные локаторы начинают указывать на другой
> элемент либо завершаются таймаутом. После каждого изменения интерфейса получай
> locator заново.
>
> Для каждого чата: клик по строке → клик по точному названию в верхней панели →
> дождаться текста «Инфо» → клик по точному тексту «Ссылки» → собирать все
> `a[href*="max.ru/join/"]`. В «Инфо» не рассчитывай на `role=tabpanel`: найди
> крупнейший видимый scroll-контейнер и прокручивай его до конца. При ошибке
> сохраняй screenshot, HTML и Playwright trace.

## Почему обычные варианты не работают

1. `page.mouse.wheel()` может прокрутить страницу или панель информации вместо
   списка чатов.
2. `[role=listitem]` включает элементы левого меню.
3. Один заранее созданный `locator(...).nth(i)` нестабилен: после клика React
   переразмечает виртуальный список.
4. Текст последнего сообщения меняется, поэтому он не должен входить в постоянный
   идентификатор чата.
5. Медленный анализ одновременно с обнаружением приводит к пропускам: новые
   сообщения поднимают диалоги наверх.

## Диагностический запуск

```powershell
py -m pip install -r requirements.txt
py -m playwright install chromium
py tools\inspect_max_all_chats.py
```

Откроется MAX с отдельным постоянным профилем. После ручного входа вернитесь в
консоль и нажмите Enter. Скрипт быстро прокрутит только список «Все» и создаст
`max_all_chats_snapshot.json`. Он ничего не открывает и не читает сообщения — это
проверка исключительно этапа обнаружения и прокрутки.
