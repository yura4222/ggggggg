# MAX Safe Sender

Безопасное ядро рассылки работает **только** по явно выбранным после сканирования
получателям. Ограничение — 20 чатов и 1–3 копии сообщения за запуск. По умолчанию
используется тестовый режим без нажатия Enter. Состояние сохраняется после каждого
чата, поэтому пауза или закрытие не создают повторных отправок.

Интеграция: получить `ChatSnapshot` через `MaxAutomation.snapshot_all_chats()`,
показать названия пользователю для множественного выбора, создать `Campaign`,
показать итоговое подтверждение и только после него вызвать `ApprovedSender.run()`.
Автоматический выбор всех найденных чатов намеренно отсутствует.
