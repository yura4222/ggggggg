# MAX Safe Sender

Безопасное ядро рассылки работает **только** по явно выбранным после сканирования
получателям. Ограничение — 20 чатов и 1–3 копии сообщения за запуск. По умолчанию
используется тестовый режим без нажатия Enter. Состояние сохраняется после каждого
чата, поэтому пауза или закрытие не создают повторных отправок.

Главное окно уже выполняет интеграцию: открывает MAX, сканирует вкладку «Все»,
показывает названия для множественного выбора, запрашивает единое подтверждение и
затем автоматически обрабатывает выбранные чаты. Автоматический выбор всех
найденных чатов намеренно отсутствует.

Можно выбрать больше 20 чатов: интерфейс разобьёт их на пакеты по 20. Первый пакет
запускается после общего подтверждения, а каждый следующий — только после нового
нажатия «ПРОДОЛЖИТЬ СЛЕДУЮЩИЙ ПАКЕТ». Нажатие сразу запускает один подготовленный
пакет без дополнительного информационного окна. Сканирование и ввод сообщения
повторять не нужно; позиция сохраняется автоматически.
